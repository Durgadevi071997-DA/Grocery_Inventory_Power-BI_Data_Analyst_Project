
## Grocery Inventory
## Project Overview
The Grocery Inventory Dashboard is a data visualization project designed to monitor and analyze sales, stock levels, supplier performance, and profitability in a grocery business. The dashboard provides a centralized view of key metrics like total sales, stock quantity, reorder levels, and category-wise performance, helping stakeholders make data-driven decisions efficiently.


## Project Objectives
Track overall sales and profit performance

Monitor inventory levels across products

Identify reorder requirements to avoid stockouts

Analyze supplier performance

Understand category-wise sales 

Improve inventory turnover and efficiency


## Dataset Description
Product_ID / Product_Name – Unique product details

Category – Product classification (Fruits, Dairy, etc.)

Supplier_Name – Supplier providing the product

Stock_Quantity – Available inventory

Reorder_Level – Minimum stock threshold

Status – Active / Backorder / Discontinued

Sales_Volume – Quantity sold

Price / Profit – Financial metrics
## Data Preparation & Transformation
Removed missing and duplicate values

Standardized column names and formats

Created calculated fields:

Total Sales

Total Profit

Average Turnover

Categorized products based on reorder status

Aggregated data for category and supplier analysis

Applied filters for dynamic dashboard interaction

## Tools & Techniques
Power BI / Excel – Dashboard creation

SQL – Data extraction and transformation

DAX (Data Analysis Expressions) – Calculations (KPIs, measures)

Data Cleaning Techniques – Handling nulls, formatting

Data Visualization – Charts, slicers, KPIs

## Analysis & Insights
Total Sales: 58K indicates strong overall performance

Total Stock: 55K shows inventory is well-maintained

High-demand products: Bread Flour and Cauliflower lead in stock usage

Category Insight: Fruits & Vegetables generate the highest revenue

Supplier Performance: Katz is the top-performing supplier

Reorder Analysis: A significant number of products require restocking

Profit Insight: Total profit of 344.27K shows healthy margins

## Conclusion
The dashboard effectively provides insights into inventory and sales performance. It helps identify high-performing products, monitor stock levels, and optimize supplier management. Businesses can use this tool to reduce stock shortages, improve profitability, and enhance operational efficiency.
